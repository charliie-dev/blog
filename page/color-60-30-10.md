# Design | The 60-30-10 Colour Rule

A simple rule for spreading colour across an interface, from Jesse Showalter's video.[^showalter]

## The rule

| Share   | Colour                 | Used for                                                                             |
| ------- | ---------------------- | ------------------------------------------------------------------------------------ |
| **60%** | Neutral or base colour | Backgrounds and large surfaces                                                       |
| **30%** | Primary colour         | Often the brand colour: important, but less so than the accent                       |
| **10%** | Action or accent colour | Only what should say "click me" or "look at me". Use it sparingly, so it keeps that pull. |
