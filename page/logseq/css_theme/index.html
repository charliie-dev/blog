Blocks and the editor

  background: var(--ls-tertiary-background-color);

  background: var(--ct-success-color);

Toolbar and layout

A browser-like toolbar

Moves the toolbar icons to the left, closer to a web browser’s layout, hides the home button and puts a gap before the plugin icons:

/* Toolbar icons */

/* Shrink the left toolbar */
.cp__header > .l {
  width: auto;
}

/* Move all icons to the left */
.cp__header > .r {
  justify-content: flex-start;
}

/* Hide the home button (I don't use it at all) */
body:not([data-page="home"]) .r > div:nth-child(2) {
  display: none !important;
}

/* Add a gap before the plugin icons and reorder them */
.ui-items-container[data-type="toolbar"] {
  margin-left: auto;
  order: 1;
}
.ui__dropdown-trigger {
  order: 2;
}
.r > div:last-child {
  display: flex !important;
  order: 3;
}

Icons and fonts for specific tags

Goal. Change how particular tags look.

How. Select a tag by its name with [data-ref="value"]. This adds 📝 after tags whose name ends in “literature note”:111213

a.tag[data-ref$="literature note"]:after {
  content: "📝";
  font-size: 16px;
}

This gives a tag its own font:

a.tag[data-ref$="TAG_NAME"] {
  font-family: "FAMILY_NAME";
}

And this puts 🚀 before references to pages whose name starts with “Go Live”:

span[data-ref^="Go Live"] .page-ref::before {
  content: "🚀";
}
