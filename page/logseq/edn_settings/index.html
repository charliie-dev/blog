Logseq | EDN_Settings

April 8, 2022

Settings that go in Logseq’s config.edn. Each section says what the setting does, then shows it; sources are collected at the bottom. CSS tweaks live in Logseq | CSS_Theme.

Macros

Progress bar

Goal. Show a small progress bar, such as 47 of 195, inside a block.

How. Add a progress entry to the :macros map. The macro renders a Hiccup progress element followed by the numbers:1

{"progress" "[:span
			 [:progress {:value $1 :max $2
              :style {:width 200
              :margin-right 4}}]
              [:small \"$1/$2\"]]"}

Call it with the current value and the maximum, for example {{progress 47,195}}. The bar’s colours and rounded corners come from CSS; the matching style is in Logseq | CSS_Theme: Progress bar.

Editor

Insert ≠ from the slash menu

Goal. Type ≠ without hunting for the character.

How. :commands adds custom entries to the slash menu. This pair adds a /!= command that inserts ≠:2

:commands
[["!=" "≠"]]

Wrap long lines in code blocks

Goal. Long lines in a code block wrap instead of scrolling sideways.

How. Pass lineWrapping through to the CodeMirror editor that Logseq uses for code blocks:3

:editor/extra-codemirror-options {:lineWrapping true}
